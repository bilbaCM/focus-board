# Focus Board

A single-page pomodoro timer + kanban-style to-do board, built with plain HTML/CSS/JavaScript — no build step, no dependencies.

## Features

- Pomodoro timer with focus (25 min), short break (5 min), and long break (15 min) modes
- Circular progress ring and browser tab title countdown
- Drag-and-drop task board with **To Do / Doing / Done** columns
- Audio cue when a timer session ends
- All state (timer + tasks) persists locally via `localStorage` — nothing leaves your browser

## Usage

Open [`index.html`](index.html) directly in any modern browser. There is nothing to install or build.

## Tech

Vanilla JavaScript (ES5-compatible), no frameworks or external libraries.
